# コスト試算・トークン検証

Gemini API および各インフラのコスト試算と、実測トークン数の記録。

## Gemini API 料金（`gemini-3.5-flash`）

| トークン種別 | 料金 |
|---|---|
| 入力（プロンプト） | $1.50 / 1Mトークン |
| 出力（レスポンス、thinking tokens含む） | $9.00 / 1Mトークン |

---

## トークン実測データ

### 検証日
2026-02-26

### 検証条件

| 条件 | 初期値テスト | 最大値テスト |
|---|---|---|
| `mealCount` | 3 | 6 |
| `days` | 3 | 3 |
| `mainIngredient` | なし | 200文字（上限） |
| `allergies` | なし | 500文字（上限） |
| `dislikedFoods` | なし | 500文字（上限） |
| `avoidFoods` | なし | 500文字（上限） |
| `fixedMeals` | なし | なし |

### 実測トークン数

| 条件 | input | output | total | 所要時間 |
|---|---|---|---|---|
| **初期値**（3食×3日） | 599 | 4,669 | 5,268 | 約10〜15秒 |
| **最大値**（6食×3日、全文字列上限） | 1,138 | 4,239 | 5,377 | 約26秒 |

> **備考**: `sanitizeUserInput` により各文字列フィールドは最大200文字にカットされるため、
> `allergies`・`dislikedFoods`・`avoidFoods` の500文字上限値はプロンプトには反映されない。
> 実際のinputトークン増加は主に `mainIngredient` と食事数に起因する。

## 1リクエストあたりのコスト試算

### 初期値ケース

```
input:  599  × $0.075 / 1,000,000 = $0.0000449
output: 4,669 × $0.30  / 1,000,000 = $0.0014007
─────────────────────────────────────────────
合計: ≒ $0.00145（約0.22円）
```

### 最大値ケース

```
input:  1,138 × $0.075 / 1,000,000 = $0.0000854
output: 4,239 × $0.30  / 1,000,000 = $0.0012717
─────────────────────────────────────────────
合計: ≒ $0.00135（約0.20円）
```

> outputが支配的なため、inputが増えてもコストはほぼ変わらない。

## インフラ料金

| サービス | プラン | 月額 | 備考 |
|---|---|---|---|
| Vercel | Hobby（無料） | $0 | 個人利用は無料枠で十分 |
| Upstash Redis | Free | $0 | 10,000コマンド/日まで無料 |
| **Gemini API** | Pay-as-you-go | 数十〜数百円 | 実質唯一のコスト |

### Upstash Redisの消費量概算

レートリミットミドルウェアは1リクエストにつき約2〜3コマンドを消費。

```
1日100リクエスト × 3コマンド = 300コマンド/日
→ 無料枠（10,000コマンド/日）の範囲内
```

## コスト管理

Google Cloud の予算アラートを設定することで支出上限の通知が可能。

- [Google Cloud Console → 請求 → 予算とアラート](https://console.cloud.google.com/billing)

また、トークン使用量は `logs/tokens-YYYY-MM-DD.log` に自動記録される（`writeTokenLog` 関数）。
