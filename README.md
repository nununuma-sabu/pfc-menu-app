# AI PFC Menu Generator

「PFCバランスを合わせるのが面倒くさい...」
「毎日何を食べるか考えるのが大変...」

そんな個人的な悩みから生まれた、**AIによる献立提案アプリ**です。
目標カロリーとPFCバランスを入力するだけで、Gemini AIがよしなに1日の献立を考えてくれます。

## なぜ作ったか
筋トレやダイエットをしていると、どうしても「PFCバランス」の計算が必要になります。
しかし、毎日「タンパク質があと20g足りない...」「脂質を抑えなきゃ...」と考えながら献立を組むのは非常にストレスでした。

「冷蔵庫にある食材や、食べたいものを指定して、あとはAIに丸投げしたい」
そんな思いで、自分用にサクッと作りました。

## 主な機能
*   **AIによる献立提案**: 指定したカロリー・PFCバランスに合わせた朝・昼・夕のメニューを提案します。
*   **食材検索エンジン**: 文科省「日本食品標準成分表」2,600件超のデータベースを搭載。表記揺れ・同義語に対応した多段フォールバック検索（AND→OR→部分一致）で、「鶏胸肉」「サーモン」「パスタ」などあいまいな入力でも正確な食材を特定します。
*   **PFCプリセット**: 「ローファット」「ケトジェニック」「増量期」など、ボタン一つで切り替え可能です。
*   **TDEE自動計算**: 体重・体脂肪率から消費カロリーを算出し、ボディメイク（リコンプ）に最適な数値を自動入力します。
*   **メイン食材指定**: 「今日は鶏胸肉を使いたい」「魚が食べたい」といった要望に対応します。
*   **除外食材の設定**: アレルギー食材・苦手な食材・避けたい食材を優先度別に細かく指定できます。
*   **食事回数・日数指定**: 1日あたりの食事回数（3〜6食）と提案日数（1〜3日）を自由に設定できます。
*   **お気に入りレシピの固定**: 特定の食事枠に決まったレシピを固定し、残りの枠のみAIに提案させることができます。
*   **PFCバランスの自動計算**: P（タンパク質）またはF（脂質）を入力すると、残りの割合をC（炭水化物）に自動計算・反映し、入力の手間とミスを防ぎます。
*   **カロリー・PFCグラフ表示**: 目標値と、提案されたメニューの合計数値を視覚的なグラフで比較・確認できます。
*   **直感的なUI**: 献立の詳細はリッチなアニメーション対応のアコーディオンでスッキリ整理され、スマートフォンでも見やすいカードデザインを採用しています。
*   **入力バリデーション**: PFCバランスの合計が100%でない場合や、固定メニューのカロリーが目標を超過している場合は、送信前にフォーム上でエラーを表示します。

### 安全性・信頼性への取り組み
*   **構造化出力 (Structured Outputs)**: Gemini APIのレスポンススキーマを厳密に定義し、AIの出力ブレによるJSON解析エラーを未然に防ぎ、安定した献立提案を実現しています。
*   **プロンプトインジェクション対策**: ユーザーの自由入力欄（メイン食材、除外食材など）に対してサニタイズ処理を行い、悪意のあるプロンプト入力からシステムを保護しています。
*   **自動リトライ＆レート制限**: Gemini APIの一時的な通信エラー発生時には適切な間隔で自動リトライを実行。また、過度な連続リクエストを防ぐレート制限（Rate Limiting）も実装し、システムの安定稼働を支えています。

## 使い方
1.  目標カロリーとPFC（またはプリセット）を設定します。
2.  必要であれば「メイン食材」を入力します。
3.  「献立を提案する」ボタンを押すだけ！
